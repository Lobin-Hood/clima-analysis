# Análisis de Datos Climáticos

## 📋 Descripción del Proyecto

Este proyecto realiza un análisis estadístico de datos meteorológicos históricos para identificar tendencias en temperatura y precipitaciones.

- **Hugo (P1):** Líder y Organizador - Estructura del proyecto y coordinación
- **Paco (P2):** Desarrollador Técnico - Lógica algorítmica y scripts
- **Luis (P3):** Revisor y QA - Documentación, revisión por pares e integración

## 🎯 Objetivo

Analizar un conjunto de datos climáticos para generar indicadores básicos de:
- Temperatura promedio
- Temperatura máxima y mínima
- Promedio de precipitaciones
- Visualización de la evolución de temperatura en el tiempo

## 📊 Dataset Utilizado

Se utiliza el dataset de temperatura global disponible en:
https://datahub.io/core/global-temp

### Características del dataset:
- Datos de temperatura promedio global
- Registros mensuales y anuales
- Formato CSV
